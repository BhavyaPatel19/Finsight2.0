      - Iterate over pages. Track `buffer`, `buffer_page`, `buffer_section`, `buffer_sub`.
      - On section boundary (current_section != buffer_section) AND buffer length > chunk_size * 0.3: flush buffer as a chunk.
      - Size-based flush: while len(buffer) >= chunk_size, find paragraph break near chunk_size using `_find_paragraph_break()`, flush, keep overlap.
      - Each chunk dict: `{"text": ..., "page_number": ..., "section": ..., "sub_section": ..., "chunk_index": ...}`

      - Return `{"status": "indexed", "document_id": document_id, "chunks": len(chunks)}`

    ```python
    @router.post("/process/{document_id}", response_model=ProcessResponse)
    def process_for_credisentiment_endpoint(
        document_id: int,
        session: Session = Depends(get_session),
        current_user: User = Depends(get_current_user),
    ):
        """Process a document for the CrediSentiment pipeline (separate from RAG)."""
        doc = session.get(Document, document_id)
        if not doc:
            raise HTTPException(status_code=404, detail="Document not found")
        if not doc.pdf_path:
            raise HTTPException(status_code=400, detail="Document has no PDF file")

        from finsight.credisentiment.pipeline import process_for_credisentiment
        result = process_for_credisentiment(session, document_id)

        if result.get("status") == "error":
            raise HTTPException(status_code=500, detail=result.get("message", "Processing failed"))

        return result
    ```
    - Uses lazy import of `process_for_credisentiment` inside the function body (consistent with heavy-import pattern used elsewhere)
    - Returns `ProcessResponse` on success, raises `HTTPException(500)` on error
    - Auth-guarded via `Depends(get_current_user)`, session via `Depends(get_session)`
